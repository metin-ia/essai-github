# essai-github

Projet d'essai public pour **GitHub dans Metin 2.0** (organisation `metin-ia`).

Un petit programme d'exemple, en JavaScript, qui calcule des prix (total, remise, TVA). Il sert à vérifier que Metin
sait relier un projet, l'analyser, proposer des améliorations et lancer les tests.

- `src/calcul.js` : les calculs ;
- `test/calcul.test.js` : les tests (`npm test`, sans aucune dépendance) ;
- `.github/workflows/tests.yml` : les tests lancés sur GitHub à chaque changement.

Rien de personnel ni de secret dans ce projet.
